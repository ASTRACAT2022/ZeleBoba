# Объём версии 1.0 — полный функциональный перенос Bedolaga

ZeleBoba PHP — независимая PHP-реализация функциональности [Bedolaga](https://github.com/BEDOLAGA-DEV/remnawave-bedolaga-telegram-bot). Исходный код не переносился; реализованы эквивалентные бизнес-процессы.

| Область | Реализовано |
|---|---|
| Веб | Регистрация, пароль, Telegram-вход, кабинет, заказы, подписки, баланс, промокоды, реферальная программа, подарки, триалы, лендинги |
| Telegram | Бот-дублер кабинета: /start, /help, /plans, /buy, /status, /orders, /subs, /cabinet, /support, /link, /login, /balance, /topup, /promo, /referral, /gift, /gift_buy, /gift_claim, /trial + deep-link вход, inline-кнопки, answerCallbackQuery, тандем с вебом |
| Кошелёк | Единый баланс, пополнение через Platega, автопокупка после пополнения (умная корзина), история транзакций, has_made_first_topup |
| Платёжные провайдеры | Platega через единый реестр + demo-адаптер |
| Промокоды | Деньги, дни подписки, триалы, скидки %, комбо деньги+дни, лимиты, first_purchase_only, анти-стакинг |
| Реферальная программа | Коды, deep-link ref_, комиссия с пополнений, бонус за первое пополнение, ступени комиссии, вывод средств с риск-скорингом |
| Подарки | Покупка с баланса, канонические коды GIFT_<59>, deep-link активация, запрет самоактивации, first-claim, идемпотентность, «Мои подарки» |
| Триалы | Бесплатные и платные, конвертация в платный in-place (тот же Remnawave-юзер), перенос остатка дней |
| Маркетинг | Рассылки по сегментам, обязательные каналы, лендинги со скидками, конкурсы с раундами, опросы с наградами, рекламные кампании с бонусами |
| Админка | RBAC (роли, права, ABAC-политики), неизменяемый аудит, отчёты по продажам, мониторинг ошибок и аномалий трафика, бэкапы с восстановлением, техработы, панель статуса |
| Эксплуатация | Docker, роли БД, health/heartbeat, backup/restore, CI, шифрование секретов, TOTP-защита админки |

## Платёжные провайдеры

Все провайдеры работают параллельно через единый `ProviderRegistry`. Каждый реализует `ProviderInterface` (createTopup, createOrder, verify, handleWebhook). Выбор провайдера — в вебе (селект на странице баланса) и в боте (кнопки в меню баланса). Webhook'и всех провайдеров принимаются на `/webhooks/<id>`.

## Кошелёк и автопокупка

- Пополнение создаёт `topups`-заказ, worker создаёт checkout у выбранного провайдера.
- После подтверждения платежа (webhook → авторитетная проверка через API) баланс зачисляется ровно один раз.
- Если пользователь сохранил корзину с intent (недостаточно средств → выбрал пополнение), после зачисления автоматически списывается баланс и завершается покупка (подписка/подарок/трафик/устройства).
- Корзина хранится в БД (таблица `carts`), intent снимается при попытке автопокупки.

## Подарки

- Токен: 64 URL-safe символа. Публичный код: `GIFT_<59>` (лимит Telegram start_param).
- Активация: deep-link `t.me/<bot>?start=GIFT_<59>`, ручной ввод кода/ссылки в боте и вебе, прямая ссылка `/buy/gift/<token>`.
- Покупатель не может активировать свой подарок; подарок закрепляется за первым активатором; повторная активация тем же получателем идемпотентна.

## Триалы

- Тариф помечается `is_trial_available`, длительность из `trial_duration_days` или `TRIAL_DURATION_DAYS`.
- Платный триал (`TRIAL_PAYMENT_ENABLED` + `trial_price_kopeks`) списывает с баланса.
- Конвертация в платный продлевает ту же подписку (тот же Remnawave-юзер/ссылка), с опцией переноса остатка дней (`TRIAL_ADD_REMAINING_DAYS_TO_PAID`).

## RBAC

- Роли (`admin_roles`) с набором прав, назначение пользователям (`user_roles`), ABAC-политики (`access_policies`).
- Legacy-админ (role='admin') получает все права.
- Неизменяемый журнал действий администраторов (`admin_audit_log`) с IP, UA, методом и путём.

## Бэкапы

- Полный SQL-дамп всех таблиц в `var/backups/backup-<timestamp>.sql`.
- Восстановление из админки с подтверждением; перезаписывает текущую БД.

## Отличия от Bedolaga

- Нет веб-кабинета на React (Bedolaga Cabinet) — кабинет встроен в PHP-приложение.
- Нет Apple IAP, фискализации НалоGo, рекуррентных карт (используются renewal-заказы).
- Нет OAuth (Google/Yandex/Discord/VK) — вход по email/паролю и Telegram.
- Нет Redis — корзина и pending-данные хранятся в PostgreSQL/SQLite.
